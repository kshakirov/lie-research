# Lie Research Project (R&D)

Инженерно-исследовательский проект по освоению теории алгебр Ли и теории представлений через призму компьютерных наук (Computer Science) и строгого математического моделирования.

## 🎯 Философия и Подход
* **Двутактный режим**: Теория, философия и концептуальные дискуссии ведутся в пути; практическая реализация, вычисления и кодинг — строго за компьютером.
* **Минимум абстрактной зубрежки**: Идем от физико-геометрического смысла и практических вычислений «руками» к общим теоремам.
* **Инженерная строгость**: Каждое математическое решение фиксируется в виде кода, документации архитектурных решений (ADR) и исследовательских логов.

## 🛠 Технологический Стек
* **Движок исследований**: Wolfram Language (`wolframscript`) для символьных вычислений и проверки алгебраических тождеств.
* **Контроль версий**: Git (чистые текстовые скрипты `.wl`, никаких бинарных блокнотов).

## 📂 Структура Проекта
* `doc/adr/` — Архитектурные и инженерные решения (Architecture Decision Records).
* `doc/research/` — Исследовательские логи, хроника дискуссий и теоретические выкладки.
* `src/` — Исполняемые скрипты для Wolfram Engine.
